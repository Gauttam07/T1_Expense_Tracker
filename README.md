# T1 Expense Tracker

## Overview

T1 Expense Tracker is a simple web-based application that helps users record and manage their daily expenses. It allows users to add, edit, and delete expenses while keeping track of the total amount spent.

## Features

* Add new expenses with name, amount, category, and date
* Edit existing expense records
* Delete expenses
* Automatic calculation of total expenses
* User-friendly table interface
* Displays currency in Indian Rupees (₹)

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Use

1. Enter the expense details (name, amount, category, and date).
2. Click **Add Expense** to save it.
3. Use the **Edit** button to update an expense.
4. Use the **Delete** button to remove an expense.
5. The total expense amount will update automatically.
